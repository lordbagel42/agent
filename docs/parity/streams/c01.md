## Shared runtime composition and failure lifetime

Main supplies its already-created process `JuneRuntime` to the optional
`Dependencies.effectRuntime` seam; it does not construct an adapter runtime or
publish a global accessor. C02 owns registry forwarding, and each consumer keeps
the original actor/step abort signal and its current-authority checks. This
injection alone does not mount task projections or enable unpublished consumers.

Once that runtime reaches registry construction, startup/shutdown failure latches
admission and retains both runtime and telemetry for existing recovery ownership.
Failure before handoff still disposes normally. The ordinary successful shutdown
sequence is unchanged. Rivet's shutdown promise can return on its grace deadline;
it is not a certificate of actor or raw-effect retirement. Runtime disposal is
also not an actor cancellation signal. No new failed-start shutdown callback,
settlement rewrite or recovery takeover is introduced.

A disposable before/after probe uses the actual root cleanup helper, real Effect
runtime and real lifecycle latch with held raw work. Before, failed cleanup
invalidated the runtime while work remained pending; after, the shared runtime
and telemetry remain available without reopening admission. Original-signal abort
does not retire the shielded wait early. Pre-handoff and normal-cleanup controls
still dispose runtime before telemetry. Actual root failure handlers preserve
ownership, and authored-recovery failure fences before waiting for client cleanup.
These are local boundary checks, not proof of all consumer cancellation paths or
live task/stop behavior; the relevant owners separately verify those workflows.

## TaskView authorization ends at first history publication

The coordinator's focused Oracle follow-up settles the additive producer facet:
`CapabilityOutputGuards.register(result: object, current: () => boolean): void`,
exposed as `readonly outputGuards?: CapabilityOutputGuards` on K1's invocation.
The internal contract version, TaskView schema and Promise ABI remain unchanged.
This declaration alone installs no collector, projection or root task mount.

C02 owns one worker-local collector per modular invocation and passes its controls
separately from the producer's distinct register-only object. S05 registers the
final schema-parsed object immediately before returning it; absence or failed
registration cannot return a non-null view. Its predicate pins the exact entry,
original source reader/incarnation/publication, current authorization/deletion and
original TTL. Null and unrelated inspection need no registration. Claiming the
exact object consumes registration once, not its guard lifetime. Duplicate,
unregistered or reused objects and throwing/asynchronous/non-true guards fail
closed; previous registrations cannot certify another result.

Claimed guards survive both outer delivery awaits, dispatcher return and every
worker preparation await through the synchronous check immediately before
`history.push`. No await separates that check from insertion. Failure substitutes
the existing bounded terminal-unavailable text, not the view. Worker-local
`finally` ends the collector after publication or abandonment, before persistence.
Worker validity, action admission, raw settlement and operation status are not
replaced by a source predicate. No transferred result handle or one-shot history
overlay is added.

The admitted minimized text is ordinary historical evidence with its original
`observedAt`/`expiresAt`, not proof of continuing freshness at a later model call
or provider dispatch. Source-only invalidation during persistence keeps that
history. Actual forgetting/deletion/revocation retains existing worker cancellation
and history clearing. Guards, raw presentation snapshots, readers and caches are
never serialized. C02/S05 must carry this distinction in their actual runtime
knowledge; S14 owns the corresponding producer-contract wording clarification.

Implementation acceptance still requires overlapping same-ID A/B reads, exact
object reuse/duplicate/malformed denials, both real-worker outer waits and a
deterministic final Promise-handoff barrier before history insertion. Include a
