# June Sandboxes

Private SvelteKit / shadcn-svelte dashboard for June's BoxLite environments.
Build, credentials, operational boundaries and installation: [docs/sandboxes.md](../docs/sandboxes.md).

The shadcn `nova` button, input, badge and tabs primitives are generated by
`shadcn-svelte@1.7.0`; tabs use Bits UI 2's `data-orientation` / `data-state`
attributes. The custom E2B-inspired theme lives in `src/app.css`.
