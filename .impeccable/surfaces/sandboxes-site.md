# Sandbox dashboard

Mode: Operate. Owner-private desktop/mobile inspection of June's worker VMs.

## Direction contract

THESIS: Show what June's sandboxes are doing without changing them. Inventory is the primary surface, not a wall of decorative charts.

OWN-WORLD: E2B-pinned reference: near-black ground, charcoal sidebar, one-pixel rules, compact sans text, monospace identifiers, orange selection, restrained semantic status colors. Use SvelteKit and shadcn-svelte.

STORY: The owner can distinguish disabled support, unavailable observations, retained disks and active compute; find a worker; inspect its real allocation and recorded activity.

FIRST VIEWPORT: A 216px sidebar, 56px breadcrumb header, compact status summary, search/filter toolbar and dense linked inventory. Runtime state is always visible. The signature interaction is selecting a sandbox to move from fleet view to its exact metadata and timestamped activity without waking it.

FORM: User-selected E2B operational console; no random direction seed applies to this explicitly pinned reference. Dark supports the owner's sustained technical inspection; light theme remains available. Mobile collapses the sidebar and retains readable row content.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Finish review

Inline finish review used the actual desktop inventory/detail and 390px mobile
captures, with the generated comparison as a direction reference, not a pixel spec.
Type, neutral ground, rule-based surfaces and dense inventory match the pinned
E2B direction. Mobile navigation/facts adapt the layout to retain readable content.
The material finding was generated tab styles targeting the wrong Bits UI data
attributes; the corrected captures place the active underlined tabs above content.
The long-image inventory ellipsis is intentional; its title and full detail value
preserve access. Synthetic identifiers appear only in local verification fixtures.
No raster assets ship. DESIGN.md records the implemented surface. Verdict: ship.
